# Маппинг хардкод-цветов → CSS-токены (globals.css)

Цель: убрать "случайные" хардкод-hex цвета из карточек/блоков по всему сайту,
свести к единой системе токенов. Токены уже объявлены в `src/app/globals.css`
(`:root`, `[data-theme="dark"]`, `[data-contrast="high"]`) — НЕ переопределяй
их значения, только используй `var(--color-*)` вместо литералов.

## ⚠️ Важное различие: `--color-warning` (#ff8c00) vs `--color-accent` (#f97316)

Два похожих оранжевых, РАЗНЫЙ смысл:
- Если оранжевый используется как **предупреждение/бейдж статуса/иконка внимания** → `var(--color-warning)`
- Если оранжевый используется как **декоративный акцент/CTA/hover/бренд** (не про "внимание") → `var(--color-accent)`
Смотри по смыслу использования (`.warningBadge`, `.alert` → warning; `.ctaButton`, `.highlight`, градиент с primary → accent).

## НЕ ТРОГАТЬ (осознанные исключения)

- `#764ba2` (декоративный фиолетовый в градиентах Chat/CartItems) — оставить как есть, не относится к бренду, уже согласовано ранее в проекте.
- Цвета соцсетей/брендов третьих лиц (VK `#4c75a3`, Telegram `#0088cc`, WhatsApp зелёный и т.п.) — это официальные цвета брендов, НЕ трогать.
- Цвета в графиках/диаграммах (chart colors, массивы цветов для визуализации данных в Admin/AiTrafficDashboard, Admin/AnalyticsDashboard) — если видишь массив из 5-8 разных цветов явно для раскраски столбцов/секторов графика — НЕ унифицировать, это осознанный дизайн для различения категорий данных. Если сомневаешься — оставь как есть и напиши about it в отчёте.
- `#ffffff` / `#000000` как чистый белый/чёрный в специфичных местах (иконки, тени с прозрачностью через rgba(0,0,0,X)) — можно оставить, если это не текст/фон основного контента (например `rgba(0,0,0,0.05)` для box-shadow — это нормально, не трогать тени с низкой непрозрачностью чёрного, если только это явно не "тень в цвет бренда").

## Общее правило

Каждая замена — это `#hexvalue` → `var(--color-token)`, БЕЗ изменения структуры
селекторов, БЕЗ изменения других свойств правила. Если значение неоднозначно
(не попадает ни в одну категорию, не бренд, не семантика) — оставь как есть и
отметь в отчёте как "не тронуто, неясный случай".
