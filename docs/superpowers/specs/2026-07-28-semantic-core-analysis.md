# Семантическое ядро и анализ частотности запросов (Вологда)

**Дата:** 28.07.2026. Источник данных: Яндекс.Вебмастер API, `search-queries/popular`, 30 дней (28.06–28.07.2026), 453 реальных запроса с показами/кликами/позицией именно нашего сайта (`servicebox35.ru`).

**Почему не Wordstat:** прямой доступ к Яндекс.Wordstat требует API Директа, доступ к которому пока не подтверждён Яндексом (заявка отложена — см. `[[yandex-metrika]]` memory, раздел про Direct API). Использованы данные Вебмастера — это фактическая статистика показов конкретно нашего сайта, что даже точнее для приоритизации, чем общий объём спроса по рынку.

## Кластеризация запросов (после фильтрации шума)

**Важно:** часть запросов содержит названия сторонних сервисов (`пда центр`, `911-ремонт`, `svm35`, `games-service`, `pdacenter.ru`) — Яндекс показывает наш сайт в одной локальной выдаче с этими компаниями по похожим запросам, но реальный интент пользователя — другая фирма. Такие запросы отфильтрованы (40 штук) перед кластеризацией — они не являются нашей SEO-возможностью.

## Главный вывод

**Это не проблема контента.** Категорийные страницы (телефоны, ноутбуки, видеокарты, приставки, телевизоры, планшеты, аккумуляторы) уже существуют, и при детальной проверке их FAQ-контент (`generateFAQSchema` в каждом `page.js`) уже неплохо покрывает реальные формулировки запросов: «сколько стоит», «гарантия», конкретные бренды/модели, сроки ремонта. Проблема — низкие позиции (в среднем 6–24, то есть низ первой — вторая/третья страница выдачи) из-за слабого внешнего ссылочного профиля. Это уже зафиксировано и прорабатывается в `docs/superpowers/plans/2026-07-24-seo-backlink-building.md` — данный анализ подтверждает и уточняет её приоритеты.

## Найденные и исправленные проблемы (в рамках этого анализа)

1. **Ложное утверждение о выездном ремонте.** FAQ страницы `/services/tv` содержал ответ «возможен выезд мастера по Вологде» — реальной услуги выездного ремонта нет (подтверждено Томой). Та же фраза была зашита в оба шаблона автогенерации мета-описаний (`Service.generateMetaDescription()` и фолбэк в `services/[...slug]/layout.js`), из-за чего **65 из 123 услуг** в базе имели это ложное утверждение в уже сохранённом `metaDescription`. Исправлено во всех трёх местах и массово в базе (бэкап — `/root/backups/metadesc-vyezd-mastera-before-20260728.json` на сервере). Формулировка предшествует этой сессии (коммит `8181383`), не связана с более ранней сегодняшней правкой дублей метаописаний.

## Найденный, но НЕ реализованный пробел — требует решения

**Категория «Ремонт компьютеров» (десктопных ПК) отсутствует полностью.** Второй по объёму реальный кластер спроса (42 запроса, 62 показа за 30 дней, часть уже на позициях 1–6, то есть первая страница выдачи) — а в базе нет ни одной услуги с упоминанием «компьютер»/«ПК»/«системный блок», и нет отдельной категорийной страницы (`/services/computers` не существует; есть только `phones`, `laptops`, `tablets`, `tv`, `videocards`, `consoles`).

Не создавал эту категорию самостоятельно — это решение о реальном ассортименте услуг (предлагаем ли мы вообще ремонт настольных ПК как отдельное направление, или это неявно покрывается ремонтом видеокарт/компонентов), а не просто правка текста. Если да — есть готовый реальный спрос, на который прямо сейчас не отвечает ни одна страница сайта.

## Как перепроверить прогресс

Через 2–4 недели после выполнения плана по бэклинкам (`2026-07-24-seo-backlink-building.md`) повторить тот же запрос к API Вебмастера и сравнить средние позиции по этим же кластерам — снижение номера позиции будет прямым сигналом эффекта.
