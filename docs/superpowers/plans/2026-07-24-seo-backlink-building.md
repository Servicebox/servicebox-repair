# Наращивание внешних ссылок (бэклинков) для SEO

**Контекст:** 24.07.2026, через Яндекс.Вебмастер API (счётчик 97888825, хост servicebox35.ru) проверены реальные позиции и ссылочный профиль сайта.

**Что показала диагностика:**
- За 30 дней: 764 показа в поиске, только 36 кликов (CTR 4.7%), 406 из 431 запросов — вообще без единого клика.
- Брендовые запросы («сервис бокс вологда», адрес) — позиция 1-2, клики есть, всё в порядке.
- Запросы новых клиентов («ремонт телефонов вологда» — позиция ~19, «ремонт компьютеров вологда» — ~22, «ремонт айфонов вологда» — ~18) — сайт показывается на 2-3 странице выдачи и получает ноль кликов. Именно эти запросы должны приводить новых клиентов.
- Внешних ссылок на сайт — 138, но из них независимых (не свои же зеркала Яндекс.Карт и не свой CRM-домен) — около 8-10. Практически нет целенаправленной работы над ссылочной массой.
- Уже частично работающие площадки, которые нашлись сами: `bestfixmasters.ru` (карточка мастера), `daiotzyv.ru` и `reviews.yandex.ru` (отзовики), `rubrikator.org` (каталог).
- `servisboks.clients.site` — старый/параллельный мини-сайт (конструктор Clients.site), до сих пор ссылается на основной домен — статус не проверен.

**Цель:** поднять позиции по некоммерческим/брендовым и особенно по коммерческим запросам новых клиентов («ремонт X вологда») за счёт наращивания качественной внешней ссылочной массы.
